# منصة الإدارة المالية الشخصية

## نبذة عن المشروع

منصة ويب باللغة العربية لإدارة الأمور المالية الشخصية، تتيح للمستخدم متابعة إيراداته ومصروفاته، وتنظيم حساباته المالية المتعددة (نقدي، بنكي، محفظة إلكترونية، بطاقة بنكية)، وتصنيف معاملاته ضمن فئات ووسوم قابلة للتخصيص، إلى جانب وضع ميزانيات دورية ومتابعة استهلاكها أولاً بأول. توفر المنصة لوحة تحكم شاملة وتقارير مالية تعطي المستخدم صورة واضحة وسريعة عن وضعه المالي.

## الحالة الحالية

هذا الإصدار عبارة عن **الواجهة الأمامية فقط**، مبنية بالكامل في **ملف HTML واحد** (`index.html`) باستخدام HTML وCSS وJavaScript دون أي إطار عمل خارجي إلزامي. البيانات تُخزَّن حالياً بشكل مؤقت داخل المتصفح (localStorage) عبر طبقة وصول بيانات (Data Access Layer) مصممة خصيصاً لتُحاكي بنية جداول قاعدة بيانات **SQLite**، بحيث يسهل لاحقاً استبدالها باستدعاءات API حقيقية متصلة بقاعدة بيانات SQLite دون تعديل واجهة المستخدم.

## المميزات الرئيسية

- 👥 **نظام مستخدمين متعدد + سوبر أدمن**: تسجيل دخول/تسجيل، مساحة شخصية تلقائية لكل مستخدم، لوحة سوبر أدمن كاملة (إدارة المستخدمين، تعليق/تفعيل، ترقية صلاحيات، سجل نشاط، تصدير بيانات مقصور عليه فقط).
- 👨‍👩‍👦 **مساحات مشتركة (Household/Workspace)**: يقدر أي مستخدم ينشئ مساحة مشتركة (زي "أسرة أحمد")، يدعو أفراداً بالبريد الإلكتروني بدور محدد (مالك/مسؤول/عضو/مشاهد)، وكل حسابات/فئات/ميزانيات/معاملات المساحة تبقى مشتركة بينهم مع تمييز مين أضاف كل معاملة.
- 💰 **إدارة المعاملات المالية**: تسجيل، تعديل، حذف منطقي (Soft Delete)، ربط بحساب وفئة ووسوم وملاحظات.
- 🏦 **إدارة الحسابات**: حسابات متعددة الأنواع (نقدي / بنكي / محفظة إلكترونية / بطاقة) مع رصيد يُحسب تلقائياً.
- 📂 **إدارة الفئات**: تصنيفات إيرادات/مصروفات بأيقونات وألوان وترتيب أولوية.
- 💵 **إدارة الميزانيات**: ميزانيات شهرية/سنوية مع نسبة الاستهلاك والمبلغ المتبقي.
- 🏷️ **إدارة الوسوم**: تنظيم إضافي للمعاملات بالبحث والتصنيف.
- 📊 **لوحة تحكم**: ملخص شامل (إيرادات، مصروفات، رصيد، عدد الحسابات/الفئات/المعاملات، أحدث العمليات، أكثر الفئات إنفاقاً).
- 📈 **تقارير وإحصائيات**: تحليل المصروفات حسب الفئة، متابعة استهلاك الميزانيات، مؤشرات مالية رئيسية.
- ⚙️ **إعدادات النظام**: العملة، تنسيق التاريخ، المنطقة الزمنية، بداية الأسبوع، السنة المالية، الثيم.
- 🔒 **التحقق من صحة البيانات وصلاحيات الأدوار**: منع إدخالات غير صحيحة، وإخفاء أزرار الإضافة/التعديل/الحذف تلقائياً حسب دور المستخدم في المساحة الحالية.

|---|---|---|
| مدير المنصة | admin@mahfaza.app | سوبر أدمن |
| أحمد محمود | ahmed@mahfaza.app | مالك مساحة "أسرة أحمد" |
| سارة أحمد | sara@mahfaza.app | مسؤولة في "أسرة أحمد" |

⚠️ **تنبيه معماري مهم**: صلاحيات الأدوار والسوبر أدمن في هذا الإصدار هي **تصميم واجهة أمامية فقط**. الفرض الفعلي والآمن لهذه الصلاحيات (منع مستخدم من الوصول لبيانات غيره فعلياً) يتطلب خادماً (Backend) حقيقياً عند الربط بقاعدة بيانات SQLite، لأن أي منطق صلاحيات مكتوب في جافاسكريبت قابل للتجاوز من متصفح المستخدم.

## هيكل البيانات (مهيأ للانتقال إلى SQLite)

طبقة البيانات في `index.html` منظمة كجداول منفصلة تماماً كما ستكون في SQLite:

| الجدول (Table) | الوصف |
|---|---|
| `users` | المستخدمون (الاسم، البريد، الدور العام، الحالة) |
| `workspaces` | المساحات (شخصية/مشتركة) |
| `workspace_members` | عضويات المستخدمين في المساحات وأدوارهم |
| `invites` | دعوات الانضمام للمساحات المشتركة |
| `audit_log` | سجل نشاط السوبر أدمن والعمليات الحساسة |
| `accounts` | الحسابات المالية (مرتبطة بمساحة) |
| `categories` | فئات الإيرادات والمصروفات (مرتبطة بمساحة) |
| `transactions` | المعاملات المالية (تدعم الحذف المنطقي عبر `is_deleted`، ومرتبطة بمساحة ومستخدم منشئ) |
| `budgets` | الميزانيات (مرتبطة بمساحة) |
| `tags` | الوسوم (مرتبطة بمساحة) |
| `transaction_tags` | جدول ربط بين المعاملات والوسوم (علاقة متعدد لمتعدد) |
| `settings` | إعدادات النظام (صف واحد) |

كل عملية قراءة/كتابة تمر عبر كائن `DB` واحد (Service Layer) بدوال مثل `getAll`, `getById`, `insert`, `update`, `softDelete`، بحيث يكفي مستقبلاً استبدال تنفيذها الداخلي (من localStorage إلى استدعاءات SQL/API حقيقية) دون أي تغيير في بقية الكود.

## هوية التصميم

- تصميم مريح للعين بخلفيات فاتحة هادئة.
- لوحة ألوان أساسية بالأخضر والأزرق.
- أيقونات كبيرة وواضحة بشكل دائري (Circular Icon Badges).
- انتقالات وحركات سلسة بين الحالات والصفحات.
- دعم كامل للغة العربية واتجاه الكتابة من اليمين لليسار (RTL).

## خارطة طريق مستقبلية

- ربط فعلي بقاعدة بيانات SQLite (Backend + API).
- نظام تسجيل دخول وصلاحيات مستخدمين.
- رسوم بيانية تفاعلية متقدمة.
- تصدير التقارير إلى PDF وExcel.
- إشعارات وتنبيهات.
- تطبيق جوال ومزامنة سحابية.
- دعم الثيم الداكن وتعدد اللغات.
